PRESENTATION SEQUENCE

Five minutes. One evidence trail.

  1. Run the pipeline

    Choose Free evidence demo or OpenAI report generation, select the period and run. Report-only API mode uses the verified B template and calls C Writer and Critic. Full AI mode adds fresh B Planning, Risk and independent review before C, using up to 5 API calls for one report-review round, or up to 7 for two. B can stop earlier if its proposal fails review. Free mode computes source excerpts in this browser.

  2. Inspect the evidence

    Open a WBS or report citation. Check the saved document version, page and line range.

  3. Change the assumptions

    Edit delay and cost inputs, then rerun to compare conditional what-if impacts.

  4. Show a stop condition

    In free mode, plant a clearly labelled TEST claim. Any report can receive a TEST stale copy. The original stays unchanged; the free claim test does not evaluate the LLM.

  5. Keep the human checkpoint

    Neither rule checks nor an LLM Critic are human approval. Live API runs show measured usage; historical OpenAI reports and Jira readback stay separate.
